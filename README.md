Running this program writes a single pickup line, spoken in a robot's voice, in which the robot offers to cross a CAPTCHA for someone it likes, doing so slowly and honestly clicking every traffic light along the way. The line is 84 characters long, so it sits comfortably inside the competition's 1-to-200 character gate for the entry file, and because the text is fixed in the source, the output file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
